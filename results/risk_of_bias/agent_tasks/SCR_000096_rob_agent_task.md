# Risk-of-bias Agent Task — SCR_000096

**Tool:** ROBINS-I (2016)
**Target result:** Postoperative acute kidney injury Within 7 days after surgery
**PDF:** C:/Users/Jason/Projects/srma-agent-toolkit/data/raw/full_text/pdfs/SCR_000096.pdf

## Agent requirements

Assess the specified result, not the study globally.
Read the full PDF and available supplements when present.
For every signalling question provide:
- response
- evidence location
- evidence summary
- rationale
- confidence

For each domain provide:
- provisional domain judgement
- domain rationale

Do not invent unreported methods.
If evidence is insufficient, explicitly record No information.

## Signalling questions

- D1 / 1.1 — Is there potential for confounding of the intervention effect?
- D1 / 1.2 — Was analysis based on participant follow-up split according to intervention received?
- D1 / 1.3 — Were important baseline confounding domains measured validly and reliably?
- D1 / 1.4 — Were important confounders controlled appropriately in the analysis?
- D1 / 1.5 — Did adjustment avoid controlling for post-intervention variables affected by intervention?
- D2 / 2.1 — Was selection into the study related to intervention and outcome?
- D2 / 2.2 — Did selection into the analysis occur after intervention initiation?
- D2 / 2.3 — Could selection processes induce an association between intervention and outcome?
- D2 / 2.4 — Were appropriate methods used to correct selection bias?
- D3 / 3.1 — Were intervention groups clearly defined?
- D3 / 3.2 — Was intervention information recorded at intervention start?
- D3 / 3.3 — Could intervention classification be affected by knowledge of outcome or outcome risk?
- D4 / 4.1 — Were there deviations from usual care beyond the intervention being compared?
- D4 / 4.2 — Were important co-interventions balanced or appropriately handled?
- D4 / 4.3 — Was intervention implementation or adherence adequate for the target effect?
- D4 / 4.4 — Was an appropriate analysis used for the target intervention effect?
- D5 / 5.1 — Were outcome data available for all or nearly all participants?
- D5 / 5.2 — Were participants excluded because of missing intervention status?
- D5 / 5.3 — Were participants excluded because of missing covariate data needed for analysis?
- D5 / 5.4 — Could missingness depend on the true outcome value?
- D5 / 5.5 — Were appropriate methods used to address missing data?
- D6 / 6.1 — Could outcome measurement be influenced by knowledge of intervention received?
- D6 / 6.2 — Were outcome assessors aware of intervention received?
- D6 / 6.3 — Were outcome assessment methods comparable across intervention groups?
- D6 / 6.4 — Were systematic outcome-measurement errors related to intervention status likely?
- D7 / 7.1 — Was the reported result selected from multiple outcome measurements?
- D7 / 7.2 — Was the reported result selected from multiple analyses of the intervention-outcome relationship?
- D7 / 7.3 — Was selection of the reported result likely based on findings?
