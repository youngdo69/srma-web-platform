## Known limits

- Plain-prose edits to eligible sections are supported. Complex inline runs, equations, citation-level editing and full structured Methods changes remain limited. Actual analysis changes use the approved Analysis workflow.
- Narrative and Pairwise Web draft routes are supported within their approved source contracts. Mixed has generic R/38, Statistical Methods, QC planning and Word rendering evidence. The current one-click Web drafting action does not cover combined Mixed.
- Native/manual Chrome acceptance, actual PostgreSQL acceptance, organization authentication, and production persistence/backup rehearsal remain NOT_VERIFIED.
- The development overlay is intentionally rejected in beta/production. Production requires an approved exact source distribution and matching external acceptance records under the existing deployment policy. Existing receipts are code-hash scoped. The packaged candidate has no production acceptance receipt.
- Live Scientific Validation requires an eligible frozen dossier, applicable R/40 evidence and actual Human decisions. Provider-backed QC was NOT_VERIFIED and no paid calls were made. An individual project retains its own submission result.

No confirmed P0 universal defect was identified in the audited scope. The candidate is ready for PM review in that scope. No release commit, remote push, tag or deployment has been performed.
